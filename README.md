# Python Security Projects

A collection of beginner-friendly Python scripts built to practise core cyber security, cryptography, and incident detection concepts alongside my **BTEC Level 3 National Extended Diploma in Computing** (*Unit 7: IT Systems Security and Encryption* & *Unit 16: Cyber Security and Incident Management*).

## Projects

### 1. Password Strength Checker & SHA-256 Hasher (`password_checker.py`)
Evaluates password complexity against basic security rules (length, uppercase, lowercase, numbers, and special characters) and demonstrates one-way cryptographic hashing using Python's built-in `hashlib` module.

**How to run:**
`python password_checker.py`

### 2. Failed-Login Log Analyser (`log_analyser.py`)
Scans simulated authentication logs for repeated failed login attempts and raises a security alert when an IP address exceeds a defined threshold—demonstrating basic brute-force detection and incident triage concepts.

**How to run:**
`python log_analyser.py`

## Disclaimer
All scripts in this repository are created strictly for educational purposes and defensive security learning.
